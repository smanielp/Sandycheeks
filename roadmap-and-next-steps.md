# Roadmap & Next Steps

> Opinionated, staged plan. Each stage has a gate: don't spend on the next stage
> until the current one returns a signal. The first dollar buys a demand signal,
> not tooling. **Do not start with the pitch deck — it's the last artifact.**

## Stage 0 — Frame the bet (now)

- [x] Stand up this repo as the organizational toolset
- [ ] Lock the beachhead decision: **surf/beach anglers first** (recommended)
- [ ] Write the one-question hypothesis you're testing:
      *"Will surf anglers pay $X for a powered, marine-grade wagon that hauls
      100+ lbs up dry sand with minimal effort?"*

## Stage 1 — Customer discovery (weeks, ~$0)

**Gate to continue:** clear, repeated demand signal + a defensible price band.

- [ ] 20–30 structured conversations with surf anglers + beach homeowners
- [ ] Capture: load weight, haul distance, frequency, current cart, biggest
      pain, willingness to pay, dealbreakers
- [ ] Fill in `market-and-competitive-landscape.md` WTP and beachhead sections

## Stage 2 — Competitive teardown (~$1–2k)

**Gate to continue:** a documented, specific gap you can engineer against.

- [ ] Buy top 3 manual beach wagons + 1 powered utility wagon
- [ ] Run the test protocol in `product-and-prototype-spec.md` on a real beach
- [ ] Complete the competitive table; photograph/film failure points
- [ ] This doubles as content + future marketing proof

## Stage 3 — Demand validation (cheap, parallel with Stage 2)

**Gate to continue:** measurable conversion (waitlist / reservations).

- [ ] Landing page with a real price + "reserve" button
- [ ] Drive targeted angler/beach-town traffic; measure conversion + email
      capture

## Stage 4 — Ugly prototype (the proof)

**Gate to continue:** demonstrated effort reduction + a demo video.

- [ ] Build the integration prototype (or retrofit kit) per the spec
- [ ] Test with measured load on dry sand, slope, distance
- [ ] Produce the demo video — the single most persuasive artifact you'll make
- [ ] File IP provisionals before any public demo, if budget allows

## Stage 5 — Business model & unit economics

**Gate to continue:** a path to acceptable margin at a price the market accepts.

- [ ] COGS estimate (integration vs. ground-up), landed cost, price point
- [ ] DTC vs. retail margin model; accessory/battery attach revenue
- [ ] Warranty/returns/liability cost assumptions (heavy object, batteries,
      saltwater claims)

## Stage 6 — Pitch deck & raise (only now)

**Built on evidence from Stages 1–5, not assertions.**

- [ ] Deck: problem → beachhead → demo video → market → business model →
      unit economics → team/ask
- [ ] The demo video and discovery quotes carry the deck; the spec doesn't

## Stage 7 — Productization (earn the right)

- [ ] Decide integrator vs. ground-up for v1 production
- [ ] Naming + brand decision (deliberately deferred until positioning is locked)
- [ ] Supply chain, certifications, tooling
