## Naming criteria (to evaluate candidates against)

Before locking a name, define what a good name does for this product:

- [ ] Works for both the angler beachhead and the affluent family scale customer
- [ ] Doesn't sound like a medical device, a toy, or an industrial tool
- [ ] Available as a .com (or close enough that a redirect works)
- [ ] Trademarkable in Class 12 (vehicles and conveyances) in the US, at minimum
- [ ] Pronounceable and spellable by someone hearing it for the first time
- [ ] Doesn't overlap with existing beach/outdoor brands
- [ ] Works on a physical product (embossed, printed, engraved — not just a URL)

## Trademark search protocol (when ready)

1. Run a USPTO TESS search (free) for each finalist in Class 12 (land vehicles)
   and Class 35 (retail/distribution, if relevant)
2. Run a Google / trademark database check for obvious conflicts in the
   outdoor/beach space
3. Check .com availability (Namecheap or similar)
4. Run finalists by an IP attorney for a clearance opinion before committing
